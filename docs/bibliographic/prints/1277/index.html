    短編集。どれも面白いし、アイデアが面白いし、小説としてそのアイデアだけで終わってないのもまた良い。
    特に気にいったのは「沈黙のリトルボーイ」は単行本のための書き下ろしだが、広島への原爆が不発に終わったIF を描いたものと、「天地および責任の創造」は旧約聖書の世界に「責任」というキーワードを持ち込んで再解釈する話の二作。

    あと、表題作の「まず牛を球とします。」はもうタイトルだけで勝利という感じ。
