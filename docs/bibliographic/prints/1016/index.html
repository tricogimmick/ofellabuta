    Note：

    ポン・ジュノの映画「パラサイト」に登場した半地下住宅など、韓国の低所得・貧困層向け住宅街やドヤ街、格安の宿泊施設や商店、廃墟など一般的な観光ガイドでは登場することのない「ヘル朝鮮」の観光ガイド。掲載されている写真の点数は多いがサイズが小さいのがやや物足りない。写真集ではないので仕方がないところではあるが。
    あくまでも刊行ガイドの体なので、関心は場所主体でそこに暮らしたり利用したりする人への関心は希薄。そこらへんが幻の名盤解放同盟の「ディープコリア」との違いか。
