    • 一枚の切符

    種別：小説
    作者：江戸川乱歩
    掲載：新青年 1923年7月
    発表年：1923年
    リンク：青空文庫
    粗筋：

    富田博士の夫人が鉄道で轢死する事件が発生。当初は自殺とみられたが、名刑事の黒田が夫人の懐中の遺書や現場の足跡から「博士による毒殺・偽装殺人」と看破し、博士は逮捕される。しかし、事件を目撃した青年・左右田五郎は、現場で拾った小さな切符をきっかけに、全く異なる独自の推理を組み立て始める――。
