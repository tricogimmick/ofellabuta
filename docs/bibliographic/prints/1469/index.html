    備　考：

    明治以降になって出現した展覧会や美術館といった美術鑑賞の場における鑑賞や批評の在り方の歴史を「声」「語り」という観点から論じたもの。　　

    『「お静かに!」の誕生』という書名の美術館等で大きな声で喋らないというマナーの成立という文化史的な側面についての言及は希薄。

    個人的には最後の「白樺派」に関するくだりが、これまで「白樺派」に興味がなかったせいもあり面白かった。
