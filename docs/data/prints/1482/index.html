    備　考：

    「危ない薬」「危ない1号」など90年代に悪趣味系サブカルの旗手であったライター、編集者の青山正明の評伝。
    青山正明の生まれから死までおおよそ時系列にそって追っているが、「突然変異」以前の出来事については基本、青山正明本人が残した文章や語ったことなので何処まで信用できるかは謎。読んだ印象としては「鬼畜」というより「ダメ人間」。

    しかし、東京公司の設立メンバー3人、一人は自殺で残り二人は行方不明なのか。諸行無常。

    カバー裏とカバーを外した表紙、帯の裏に、本編に収まらなかった橘玲と鵜野義嗣へのインタビューが掲載されている。
